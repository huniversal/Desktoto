설치

한 줄로 설치하거나, 파일로 받으세요.

Homebrew로 설치

터미널을 쓴다면 가장 편해요. 설치하면서 다운로드 표시를 지워 주어서 처음 실행할 때 경고가 나오지 않아요.

$brew install --cask huniversal/tap/desktoto

새 버전은 brew upgrade --cask desktoto
지우려면 brew uninstall --cask desktoto

macOS 26 이상Apple SiliconIntel Mac은 지원하지 않아요

dmg로 설치

  1. Desktoto.dmg를 받아 열고, Desktoto를 응용 프로그램 폴더로 끌어다 놓아요.
  2. 처음 열면 개발자를 확인할 수 없다는 경고가 떠요. 창을 닫아요.
  3. 시스템 설정, 개인정보 보호 및 보안 맨 아래에서 “그래도 열기”를 누르고 암호를 입력해요.
  4. 다시 열면 메뉴바에 캐릭터가 나타나요.

터미널이 편하다면 이 명령으로 경고 없이 열 수도 있어요.

$xattr -dr com.apple.quarantine /Applications/Desktoto.app

문제

세션을 여러 개 돌리면, 놓치게 돼요.

다른 창에서 작업하다가, 끝난 지 한참 뒤에야 알게 돼요.

승인 창이 떠 있어서 AI가 멈춰 있는데, 그걸 모르고 기다려요.

상태

캐릭터가 지금 상황을 알려 줘요.

달리는 중

작업이 진행 중이에요. 여러 세션 중 하나라도 돌고 있으면 계속 달려요.

폭죽

작업이 끝났어요. 캐릭터 뒤에서 작은 폭죽이 터지고 macOS 알림이 와요.

물음표

승인이나 답변이 필요해요. 사람을 기다리는 세션이 있으면 물음표가 떠요.

보라색 점

확인하지 않은 완료가 있어요. 패널을 열어서 확인하면 사라져요.

개인정보

내 대화는 컴퓨터 밖으로 나가지 않아요.

Desktoto는 대화 내용을 인터넷에 보내지 않아요. 내 컴퓨터에 이미 있는 기록을 읽기만 하고, Codex 사용량만 Codex 프로그램에 물어봐요.

읽는 것

~/.claude/projects와 ~/.codex/sessions의 세션 기록과 Claude 데스크탑 앱의 세션 정보, 임시로 저장해 둔 사용량 응답에서 제목, 모델, 토큰 사용량, 한도 사용률, 응답이 끝났는지 같은 상태만 써요. 로그인 정보는 읽지 않아요.

하지 않는 것

대화 내용을 밖으로 보내거나 따로 저장하지 않아요. 계정 정보도 다루지 않아요.

새 버전 확인

새 버전이 나왔는지 GitHub의 최신 릴리스 정보를 읽어요. 대화나 계정 정보는 보내지 않아요. 다만 GitHub 연결에 IP 주소와 Desktoto User-Agent가 전달돼요. 우클릭 메뉴의 업데이트 확인에서 끌 수 있어요.

설정 파일

Claude Code를 쓰고 있으면 ~/.claude/settings.json에 승인 대기 hook과 사용량 statusLine 두 항목을 추가해요. 바꾸기 전에 백업을 만들고, 우클릭 메뉴의 Claude 연동에서 언제든 해제할 수 있어요.

알아 두세요

Desktoto는 수익을 목적으로 하지 않는 무료 프로젝트예요. 광고도, 결제도 없어요.

캐릭터는 Claude Code의 마스코트에서 영감을 받은 팬 작품이에요. Claude는 Anthropic의, Codex는 OpenAI의 상표이고, Desktoto는 두 회사의 공식 제품이 아니에요.
