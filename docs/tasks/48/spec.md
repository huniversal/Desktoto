- specRevision: 3

## 목적

dmg로 설치한 유저가 첫 실행 경고 뒤 시스템 설정에서 어디를 눌러야 할지 헤맨다(노션 "배포 후 버그 리스트" 1번).
설치 섹션의 텍스트 4단계만으로는 "그래도 열기" 위치를 알 수 없으므로, 히어로 데모처럼 자동으로 반복되는 인터랙션으로
경고창, 시스템 설정 이동, 그래도 열기, 암호 입력, 메뉴바 캐릭터 등장까지의 흐름을 보여 준다.

## 작업 범위

### 포함

- `apps/web/index.html` 설치 섹션 왼쪽 열(다운로드 버튼 아래)에 정사각형 설치 흐름 애니메이션 무대 추가 (히어로의 `.tour` 무대 스타일과 커서, 클릭 물결, 보일 때만 재생하는 방식을 따른다). 자막은 장면을 가리지 않도록 정사각형 바로 아래에 둔다.
- dmg 설치 목록 위에 "왜 이런 과정이 필요한가요?" 설명 박스 추가
- 단계 목록(`install.step2`, `install.step3`)을 실제 macOS 문구에 맞게 수정하고, 애니메이션 진행에 맞춰 현재 단계를 강조
- 한국어와 영어 문구(`STAGE_TEXT`, `EN`) 추가와 수정
- 움직임 줄임 설정의 정지 장면, 다크 모드, 모바일 폭 대응
- 개인정보 섹션 문구를 간결하게 정리하고 특정 도구 이름과 읽는 경로를 일반 표현으로 교체 (한국어와 영어). 이슈 본문 범위 밖이지만 사용자 요청으로 같은 브랜치에서 함께 다룬다.

### 제외

- Developer ID 서명과 공증, curl 설치 스크립트, dmg 배경 이미지(별도 이슈로 다룬다)
- Homebrew 안내 변경
- 앱(`apps/macos`) 코드와 릴리스 워크플로 변경
- `docs/images/readme/install.png` 갱신 여부는 작업 후 판단한다

## 설계 결정

- 파일 구조와 로직의 책임: 별도 파일을 만들지 않고 정적 `index.html` 한 파일 안에서 처리한다(`apps/web/README.md`의 빌드 없는 구조 유지). 마크업과 장면 진행은 `buildInstallTour`가 맡고, 문구는 기존 `data-st` 방식으로 `STAGE_TEXT`에서 가져와 언어 전환이 그대로 적용된다.
- 상태와 데이터 흐름: 장면은 경고창, 시스템 설정(개인정보 보호 및 보안 이동과 스크롤, 그래도 열기 클릭), 암호 입력, 메뉴바 캐릭터 등장 순서로 반복한다. 화면에서 벗어나거나 탭이 가려지면 다음 동작으로 넘어가지 않고 기다린다.
- 선택한 방식과 이유: 화면 녹화 영상 대신 HTML, CSS, JS 애니메이션을 쓴다. 벡터라 선명하고 한국어와 영어, 다크 모드를 지원하며 바이너리 파일이 늘지 않는다. 문구와 위치는 2026-11-04에 이 Mac의 macOS(sw_vers 27.0.1, 빌드 26A434)에서 직접 확인한 것을 따른다.
- 예외 처리: `prefers-reduced-motion`에서는 "그래도 열기"가 보이는 정지 장면만 보여 준다. 암호 입력창은 실제 문구를 확인하지 못해 일반적인 표현을 쓴다. "예시 화면" 같은 별도 안내 문구는 두지 않는다(사용자 요청). 암호창은 제목줄에 붙는 시트가 아니라 모서리가 모두 둥근 떠 있는 창으로 그리고, 나타날 때 뒤 화면을 살짝 어둡게 하며 숨길 때는 투명해진다.
- 개인정보 문구: 나중에 Gemini 같은 도구가 추가되어도 고치지 않도록 `~/.claude/projects` 같은 경로와 Codex 전용 문장을 빼고 "AI 도구", "설치된 AI 프로그램" 같은 일반 표현을 쓴다. 설정 파일 항목은 실제로 `~/.claude/settings.json`을 수정하는 동작이라 그대로 둔다.

## 완료 조건

- AC-1: 설치 섹션에 경고창 "완료", 개인정보 보호 및 보안 이동, "보안" 영역의 "그래도 열기", 암호 입력, 메뉴바 캐릭터 등장을 순서대로 보여 주는 반복 애니메이션이 있다.
- AC-2: 경고창과 시스템 설정의 문구와 배치가 직접 확인한 실제 화면과 같다("열지 않음", "휴지통으로 이동", "완료", "Mac을 보호하기 위해 ... 차단했습니다", "그래도 열기").
- AC-3: 단계 목록이 "휴지통으로 이동이 아니라 완료", "보안 영역", "약 1시간 동안만 보임"을 안내하고, 애니메이션 진행에 맞춰 현재 단계가 강조된다.
- AC-4: 한국어와 영어 전환에 애니메이션 문구가 모두 따라간다.
- AC-5: 움직임 줄임 설정에서는 자동 재생 없이 "그래도 열기"가 보이는 정지 장면이 나온다.
- AC-6: 화면에서 벗어나거나 탭이 가려지면 진행이 멈추고 돌아오면 이어진다.
- AC-7: 375px 폭에서 가로 스크롤이 생기지 않고 문구가 잘리지 않으며, 다크 모드에서도 정상으로 보인다.
- AC-8: `bash .github/scripts/check-web.sh`를 통과하고 브라우저 콘솔 오류가 없다.
- AC-9: dmg 설치 목록 위에 Gatekeeper 경고가 뜨는 이유(공증 전이라 Apple이 확인하지 못함, 한 번 허용하면 예외로 저장)를 설명하는 박스가 있고 한국어와 영어로 바뀐다.
- AC-10: 암호창은 모서리가 모두 둥근 떠 있는 창으로 나타나고 뒤 화면이 살짝 어두워지며, 숨겨진 상태에서는 그림자가 보이지 않고 위쪽이 잘려 보이지 않는다.
- AC-11: 개인정보 섹션에 읽는 경로와 특정 도구 이름(Codex 전용 문장 포함)이 없고, "읽는 것", "새 버전 확인", "설정 파일" 문구가 간결하게 정리되어 있으며 한국어와 영어가 같은 내용이다. "하지 않는 것"과 설정 파일의 `~/.claude/settings.json` 안내는 유지된다.

## 검증 방법

| 완료 조건 | 확인 방법 | 기대 결과 |
|---|---|---|
| AC-1 | `python3 -m http.server 5173 -d apps/web`로 열고 설치 섹션을 한 바퀴 관찰 | 5개 장면이 순서대로 재생되고 반복 |
| AC-2 | 직접 캡처한 실제 문구와 화면 문구 대조 | 문구와 배치 일치 |
| AC-3 | 재생 중 단계 목록 관찰 | 현재 단계만 강조되고 문구가 갱신됨 |
| AC-4 | 우측 상단 언어 전환 | 무대 안 문구가 영어로 바뀜 |
| AC-5 | 시스템 설정의 손쉬운 사용에서 동작 줄이기를 켜고 새로고침 | 정지 장면만 표시 |
| AC-6 | 설치 섹션 밖으로 스크롤했다 돌아오기, 다른 탭으로 전환했다 돌아오기 | 멈췄다가 이어서 재생 |
| AC-7 | 브라우저 폭 375px, 라이트와 다크 확인 | 가로 스크롤 없음, 대비와 문구 정상 |
| AC-8 | `bash .github/scripts/check-web.sh`, 브라우저 콘솔 확인 | 통과, 오류 없음 |
| AC-9 | 설치 섹션의 dmg 항목 확인, 언어 전환 | 설명 박스가 목록 위에 보이고 영어로도 바뀜 |
| AC-10 | 암호 입력 직전과 직후 장면을 확대해 확인 | 번지는 그림자와 잘림이 없고 모서리가 둥근 창으로 보임 |
| AC-11 | 개인정보 섹션을 한국어와 영어로 보고 경로 문자열 검색 | 경로와 Codex 전용 문장이 없고 두 언어 내용이 같음 |

## 검증 결과 (2026-11-04)

`bash .github/scripts/check-web.sh`는 개인정보 문구 수정 후에도 통과했다. 로컬에서 `python3 -m http.server 5173 -d apps/web`로 확인했다.

| 완료 조건 | 결과 | 비고 |
|---|---|---|
| AC-1, AC-2 | 확인 | 이 Mac에서 직접 확인한 경고창과 시스템 설정 문구를 기준으로 그렸다. |
| AC-3, AC-4 | 확인 | 단계 목록 강조와 한국어, 영어 전환을 확인했다. |
| AC-5 | 부분 확인 | 스크립트 쪽 설정만 켠 임시 사본으로 정지 장면, 커서 숨김, 8초간 상태 고정을 확인했다. CSS의 `prefers-reduced-motion` 규칙은 직접 검증하지 못했다. |
| AC-6 | 부분 확인 | 화면 밖에서 12.5초간 진행이 멈추고 돌아오면 이어지는 것을 확인했다. 탭 숨김(`document.hidden`)은 히어로와 같은 코드라 따로 시험하지 않았다. |
| AC-7 | 확인 | 375px에서 가로 스크롤 없음(scrollWidth 375), 다크 모드 확인. 암호창 수정 후에도 모바일에서 다시 확인했다. |
| AC-8 | 확인 | check-web 통과. 콘솔 오류는 로컬에서 막히는 Cloudflare 분석 비콘뿐이다. |
| AC-9, AC-10 | 확인 | 설명 박스와 영어 전환, 실제 재생 중 암호창을 확인했다. |
| AC-11 | 확인 | 경로 문자열이 남아 있지 않고 모바일과 데스크톱 렌더링을 확인했다. |

## 미결정 사항

- "그래도 열기" 뒤 암호 입력창의 실제 문구는 확인하지 못했다. 구현을 막지 않으며 일반 표현으로 대체했다.
- 개인정보 소개 문단의 "설치된 AI 프로그램"은 지금 동작(Codex에만 사용량을 물어봄)보다 넓게 읽힐 수 있다. 다른 도구가 실제로 추가될 때 사실과 맞는지 다시 확인한다.
- 일시정지 버튼은 히어로 데모와 맞춰 넣지 않는다. 필요하면 후속으로 히어로와 함께 검토한다.
- `docs/images/readme/install.png` 갱신 여부는 작업 후 정한다.
