# 작업 명세: [Feat] 랜딩 페이지 업데이트

## 연결 정보

- 이슈: #72 / https://github.com/huniversal/Desktoto/issues/72
- 브랜치: feat/landing-update/#72
- specRevision: 1
- 대상 ai-run 원본: N/A (#70에서 추가한 Desktoto 자체 기능을 소개하는 작업)

## 목적

#70에서 노치 봇 표시 위치와 메뉴바 기본 캐릭터 토토를 추가했다.
랜딩 페이지 히어로는 아직 메뉴바의 Claude 캐릭터를 메인으로 보여 준다.
Desktoto 고유 캐릭터인 토토와 새 표시 위치인 노치 봇이 첫 화면에 드러나도록 히어로 문구와 데모를 바꾼다.

## 작업 범위

### 포함

- 히어로 제목 변경
  - 한국어: `AI가 일하는 동안,<br>지켜보세요.`
  - 영어: `While AI works,<br>keep an eye on it.`
- 히어로 리드 첫 줄 변경
  - 한국어: `Desktoto는 AI Agent 세션의 진행 상태를 메뉴바나 노치의 작은 캐릭터로 보여줘요.`
  - 영어: `Desktoto shows the status of your AI agent sessions as a small character in the menu bar or notch.`
- 히어로 데모(`#heroStage`)의 메뉴바 Claude 아이콘을 노치 봇으로 교체
- 노치 봇의 눈과 몸 색을 웹 캔버스로 그리는 코드 추가
- 움직임 줄이기 설정(`prefers-reduced-motion`)에서는 멈춘 장면으로 표시

### 제외

- `#states` 상태 설명 줄, 캐릭터 고르기 메뉴 모형, 기능 카드, 푸터 문구 수정 (이슈 ETC의 후보, 범위 확정 전)
- 앱(`apps/macos`) 코드와 표시 위치 기본값 변경
- 새 이미지나 영상 에셋 추가

## 설계 결정

- 파일 구조와 로직의 책임
  - 수정 파일은 `apps/web/index.html` 하나다. 랜딩 페이지가 한 파일에 CSS, 마크업, 스크립트를 담는 기존 구조를 따른다.
  - 기존 `Sprite`(Claude 모양 엔진)는 `#states` 줄과 다른 곳에서 계속 쓰므로 고치지 않는다. 노치 봇 그리기는 별도 함수로 추가한다.
- 상태와 데이터 흐름
  - 히어로 데모의 장면 흐름(커서가 캐릭터를 누름, 패널이 열림, 세션 카드를 누름, 해당 창이 앞으로 나옴)은 유지하고, 누르는 대상만 메뉴바 아이콘에서 노치 봇으로 바꾼다.
  - 노치 봇은 작업 중 상태로 몸 색이 돈다. 기존 전역 애니메이션 루프(`loop`)의 틱을 함께 쓴다.
- 선택한 방식과 이유
  - 모양과 색은 앱의 `apps/macos/Sources/MenuBarIcon/NotchBotView.swift`와 `apps/macos/Sources/MenuBarIcon/TotoArt.swift` 값을 따른다. 접힌 모서리 반경 12pt, 노치 밖으로 튀어나온 폭 26pt, 기울어진 알약 눈, 블루 퍼플 작업 색이다.
  - 각도 그라데이션은 캔버스의 `createConicGradient`로 그린다. 앱처럼 부채꼴을 나눠 칠할 필요가 없다.
  - 데모 무대의 메뉴바 가운데에 검은 노치를 그리고, 그 오른쪽에 노치 봇을 붙인다.
- 예외 처리
  - `createConicGradient`가 없는 브라우저에서는 단색 작업 색으로 칠한다.
  - 움직임 줄이기 설정에서는 색 회전을 멈추고, 기존처럼 패널이 열린 정지 장면을 보여 준다.

## 완료 조건

- AC-1: 한국어와 영어 히어로 제목, 리드가 포함 범위의 문구로 바뀌어 있다.
- AC-2: 히어로 데모 메뉴바에 Claude 아이콘이 없고, 가운데 노치 오른쪽에 노치 봇이 보인다.
- AC-3: 노치 봇의 몸 색이 작업 중 색으로 돌고, 커서가 노치 봇을 누르면 세션 패널이 열리는 흐름이 끝까지 돈다.
- AC-4: 움직임 줄이기 설정에서 애니메이션 없이 정지 장면이 보인다.
- AC-5: 데스크톱과 375px 폭에서 가로 스크롤이 없고, 라이트와 다크 화면 모두 노치 봇이 배경에 묻히지 않는다.
- AC-6: 다른 섹션의 `Sprite` 캐릭터(`#states` 줄 등)는 전과 같이 그려진다.

| 완료 조건 | 확인 방법 | 기대 결과 |

| AC-2 | 히어로 데모 스크린샷 | 노치와 노치 봇이 보이고 Claude 아이콘이 없다 |

| AC-6 | `#states` 섹션 확인, 콘솔 오류 확인 | 기존 캐릭터가 그대로고 콘솔 오류가 없다 |

## 미결정 사항

- 노치 봇을 누른 뒤 열리는 화면: 앱처럼 노치가 펼쳐지는 확장 패널을 보여 줄지, 기존 히어로의 세션 패널을 그대로 쓸지. 구현을 막지는 않으며, 기본은 기존 세션 패널 유지로 진행한다.
- 데모에서 눈이 커서를 따라가는 동작을 넣을지. 구현을 막지 않는다.
- 이슈 ETC 후보(`#states` 문구, 캐릭터 목록에 토토 추가, 표시 위치 기능 카드, 푸터 문구)의 포함 여부. 정해지면 specRevision을 올린다.
