# 작업 명세: [Feat] 랜딩 페이지 업데이트

## 연결 정보

- 이슈: #72 / https://github.com/huniversal/Desktoto/issues/72
- 브랜치: feat/landing-update/#72
- specRevision: 4
- 대상 ai-run 원본: N/A (#70에서 추가한 Desktoto 자체 기능을 소개하는 작업)

## 목적

#70에서 노치 봇 표시 위치와 메뉴바 기본 캐릭터 토토를 추가했다.
랜딩 페이지 히어로는 아직 메뉴바의 Claude 캐릭터를 메인으로 보여 준다.
Desktoto 고유 캐릭터인 토토와 새 표시 위치인 노치 봇이 첫 화면에 드러나도록 히어로 문구와 데모를 바꾼다.

## 작업 범위

### 포함

- 히어로 제목 변경
  - 한국어: `AI가 일하는 동안, 지켜보세요.` (데스크톱 한 줄, 좁은 화면에서는 쉼표 뒤에서 줄바꿈)
  - 영어: `While AI works, keep an eye on it.`
- 히어로 리드 첫 줄 변경
  - 한국어: `Desktoto는 AI Agent 세션의 진행 상태를 메뉴바나 노치의 작은 캐릭터로 보여줘요.`
  - 영어: `Desktoto shows the status of your AI agent sessions as a small character in the menu bar or notch.`
- 히어로 데모(`#heroStage`)의 메뉴바 Claude 아이콘을 노치 봇으로 교체
- 노치 봇의 눈과 몸 색을 웹 캔버스로 그리는 코드 추가
- 움직임 줄이기 설정(`prefers-reduced-motion`)에서는 멈춘 장면으로 표시
- 치이카와 이벤트 배너(`#eventBanner`)를 `hidden`으로 숨김 (마크업, CSS, 스크립트는 다음 이벤트를 위해 남김)
- 히어로 무대(`.tour`)를 키움: MacBook 화면과 같은 16:10 비율(최소 높이 480px), 폭은 본문 폭을 넘어 최대 1240px
- 히어로 무대에 노트북 화면 베젤을 두르고 노치에 카메라 점 표시 (하판은 두지 않음)
- 노치 봇을 누르면 앱처럼 노치 자체가 펼쳐지고, 맨 윗줄에 진행 요약, 아래에 Claude와 Codex 사용량 카드, 세션 카드 표시
- 작업 색이 봇 오른쪽 위 오목 곡선까지 이어지게 표시
- 헤더와 히어로 문구를 히어로 무대 폭(최대 1240px)에 맞추고 히어로 위아래 여백을 늘림
- 히어로 화면 아래에 Dock 추가 (설치된 앱의 공식 아이콘 .icns를 PNG로 바꿔 `apps/web/dock-icons/`에 둠)
- 상태 섹션 다섯 칸을 토토로 그리고 제목과 설명을 토토 기준으로 바꿈 (작업 중, 완료, 승인 대기, 보라색 점, 졸음)
- 메뉴바 캐릭터 고르기 섹션 삭제 (캐릭터 이미지 파일은 남김)
- 설치 안내 데모의 메뉴바 캐릭터를 토토로 바꾸고, 쓰지 않게 된 `Sprite` 엔진 삭제
- 푸터의 마스코트 팬 작품 문구를 상표 안내로 교체
- 앱 아이콘(`apps/macos/scripts/make-icon.swift`)과 파비콘(`favicon.svg`, `favicon.ico`, `apple-touch-icon.png`)을 토토 디자인으로 교체
- 노치 모드 장면 뒤에 봇이 물방울처럼 노치에서 늘어나 떨어지고(SVG 끈적임 필터), 메뉴바 줄을 따라 통통 튀어 토토 자리로 가고, 메뉴바 모드(토토 몸 색, 유리 패널, 창 전환) 장면 전체를 재생한 뒤 다시 노치로 돌아가는 반복

### 제외

- 기능 섹션의 표시 위치 카드
- 앱 동작 코드와 표시 위치 기본값 변경 (앱 쪽은 아이콘 생성기만 바꿈)
- 링크 미리보기 이미지(`og-v2.png`) 교체
- 노트북 하판 (시도했으나 어색해서 뺌)

## 설계 결정

- 파일 구조와 로직의 책임
  - 랜딩 페이지는 한 파일(`apps/web/index.html`)에 CSS, 마크업, 스크립트를 담는 기존 구조를 따른다. 아이콘 에셋만 별도 파일이다.
  - 노치 봇과 메뉴바 토토는 DOM과 CSS로, 상태 카드의 토토는 캔버스로 그린다. 기존 `Sprite`(Claude 모양 엔진)는 쓰는 곳이 없어져 지웠다.
- 상태와 데이터 흐름
  - 히어로 데모의 장면 흐름(커서가 캐릭터를 누름, 패널이 열림, 세션 카드를 누름, 해당 창이 앞으로 나옴)은 유지하고, 누르는 대상만 메뉴바 아이콘에서 노치 봇으로 바꾼다.
  - 노치 봇은 작업 중 상태로 몸 색이 돈다(CSS 각도 그라데이션 회전).
  - 노치와 메뉴바 사이 전환은 Web Animations로 재생한다. 떨어질 때 5초, 붙을 때 4.8초이고, 노치 폭은 캐릭터 위치를 따라 줄고 는다.
- 선택한 방식과 이유
  - 모양과 색은 앱의 `apps/macos/Sources/MenuBarIcon/NotchBotView.swift`와 `apps/macos/Sources/MenuBarIcon/TotoArt.swift` 값을 따른다. 접힌 모서리 반경 12pt, 노치 밖으로 튀어나온 폭 26pt, 기울어진 알약 눈, 블루 퍼플 작업 색이다.
  - 각도 그라데이션은 캔버스의 `createConicGradient`로 그린다. 앱처럼 부채꼴을 나눠 칠할 필요가 없다.
  - 데모 무대의 메뉴바 가운데에 검은 노치를 그리고, 그 오른쪽에 노치 봇을 붙인다.
- 예외 처리
  - `createConicGradient`가 없는 브라우저에서는 단색 작업 색으로 칠한다.
  - 움직임 줄이기 설정에서는 색 회전을 멈추고, 기존처럼 패널이 열린 정지 장면을 보여 준다.

## 완료 조건

- AC-1: 한국어와 영어 히어로 제목, 리드가 포함 범위의 문구로 바뀌어 있다.
- AC-2: 히어로 데모 메뉴바에 Claude 아이콘이 없고, 가운데 노치 오른쪽에 노치 봇이 보인다.
- AC-3: 노치 봇의 몸 색이 작업 중 색으로 돌고, 커서가 노치 봇을 누르면 노치가 펼쳐져 사용량과 세션 카드가 보이고, 세션을 누르면 노치가 접히며 해당 창이 앞으로 나오는 흐름이 끝까지 돈다.
- AC-4: 움직임 줄이기 설정에서 애니메이션 없이 정지 장면이 보인다.
- AC-5: 데스크톱과 375px 폭에서 가로 스크롤이 없고, 라이트와 다크 화면 모두 노치 봇이 배경에 묻히지 않는다.
- AC-9: 노치 봇이 토토로 바뀌어 메뉴바로 옮겨 가고, 메뉴바 장면을 마친 뒤 다시 노치 봇으로 돌아온다.
- AC-7: 히어로 위에 치이카와 배너가 보이지 않는다.
- AC-8: 히어로 무대가 데스크톱에서 16:10 비율, 본문 폭보다 넓게(최대 1240px) 보인다.
- AC-6: 상태 섹션 다섯 칸이 토토로 그려지고 콘솔 오류가 없다.
- AC-10: 앱 아이콘과 파비콘이 토토 디자인이고 앱 빌드 스크립트가 성공한다.
