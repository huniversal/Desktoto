# 작업 명세: [Feat] 랜딩 페이지에 바뀐 토토 캐릭터 반영

## 연결 정보

- 이슈: #77 / https://github.com/huniversal/Desktoto/issues/77
- 브랜치: feat/landing-character/#77
- specRevision: 2
- 대상 ai-run 원본: N/A (#75에서 바꾼 Desktoto 자체 캐릭터를 소개하는 작업)

## 목적

#75에서 토토의 모양과 상태 표현, 노치와 상단바 사이 물방울 전환이 바뀌었다.
지금 히어로는 문구 아래에 작은 Mac 목업이 따로 놓여 있어 상단바의 작은 움직임이 잘 보이지 않는다.
첫 화면 전체를 히어로로 쓰고, 카메라가 토토를 확대해 따라가는 연출로 바뀐 캐릭터를 크게 보여 준다.
상태와 기능 섹션도 바뀐 토토와 히어로 분위기에 맞춘다.
참고 레퍼런스는 https://www.apple.com/kr/iphone-duo/ 의 전체 화면 히어로다.

## 작업 범위

### 포함

- 히어로
  - 첫 화면 전체(100svh)를 검정 바탕으로 쓰고, 노트북 베젤 화면을 그 위에 둠. 검정은 반투명 헤더 뒤까지 이어짐
  - 자동 재생 카메라 연출: 노치 토토 확대(데스크톱 3.2배, 모바일 1.6배), 물방울 전환을 따라감, 줌아웃
  - 줌아웃 뒤 넓은 화면(1100px 이상)은 노트북이 오른쪽 아래로 비켜나 일부가 잘리고, 왼쪽 어두운 막 위에 문구와 버튼이 나타남
  - 1100px 미만은 가운데 겹친 배치, 640px 이하 모바일은 문구를 위에 두고 노트북을 실제 크기로 오른쪽 아래에 걸친 뒤 줌아웃 끝에 0.65배로 줄임(버튼 아래 40px)
  - 막이 깔린 뒤에도 막 아래에서 상태 데모가 계속 반복됨
  - 물방울 전환을 앱 `PlacementTransitionMotion.swift`의 계산과 `PlacementTransitionView.swift`의 그리기 방식(한 캔버스, 끈적임 필터, 몸 색, 만두 모양, 오목 곡선, 눈)으로 옮김. 재생 시간 3초
  - 진행 중인 작업 색을 전환 내내 유지하고 도착한 캐릭터가 이어받음
  - 상단바 토토를 만두 모양(34px)으로 키우고, 1100px 이상에서는 배터리, 검색, 제어 센터 아이콘을 토토 오른쪽에 둠
  - 노치 위 오목 곡선을 벡터 마스크로 깎아 확대해도 번지지 않게 함
  - 새로고침하면 맨 위에서 시작, 움직임 줄이기 설정에서는 연출 없이 최종 화면
- 상태 섹션: 토토를 만두 모양과 앱 눈 비율로 그리고, 보라색 점 대신 민트 초록 몸, 졸음은 납작한 몸. 큰 검정 카드를 가로로 넘기는 갤러리와 이전, 다음 버튼
- 기능 섹션: 크기가 다른 밝은 타일의 벤토 그리드(세션 패널 2칸, 꾸미기 한 줄 전체)
- 설치 데모의 상단바 토토도 만두 모양으로 바꿈
- 한국어 문구의 표시 위치 이름을 앱과 같이 상단바로 바꾸고, 페이지 설명에 노치를 함께 적음

### 제외

- 문제 섹션과 개인정보 섹션 디자인
- 링크 미리보기 이미지(`og-v2.png`) 교체
- 앱 동작 코드 변경
- 숨겨 둔 치이카와 이벤트 배너 문구

## 설계 결정

- 파일 구조와 로직의 책임
  - 기존처럼 `apps/web/index.html` 한 파일의 CSS, 마크업, 스크립트를 고친다.
  - 물방울 전환은 캔버스 하나(`.nb-canvas`)에 매 프레임 그리고, 그리는 동안 진짜 노치 봇은 숨긴다.
- 상태와 데이터 흐름
  - 카메라는 노트북 프레임 전체에 transform을 걸어 헤더 아래 영역 가운데로 토토를 끌어온다. 연출 뒤 transform은 배치 클래스(`.hero.shifted`)로 넘긴다.
  - 모바일 노트북 위치와 넓은 화면 패널 이동 거리는 스크립트가 화면 크기, 언어, 폰트 변경 때 다시 잰다.
- 선택한 방식과 이유
  - 자동 재생: 첫 화면 하나로 끝나서 단순하고 모바일에서도 안정적이다.
  - 전환을 DOM 여러 겹이 아닌 캔버스 한 장으로 그림: 색, 곡선, 끈적한 모양이 따로 그려져 어긋나던 문제를 없앤다.
  - 상태는 가로 갤러리, 기능은 고정 벤토 그리드로 나눠 섹션마다 결을 다르게 한다.
- 예외 처리
  - 섹션 주소(#install 등)로 들어오면 스크롤 복원을 그대로 둔다.
  - 갤러리 줄이 본문 밖으로 넓어지는 가로 넘침은 `body`의 `overflow-x: clip`으로 자른다.

## 완료 조건

- AC-1: 첫 화면이 너비와 높이를 꽉 채운 히어로로 보이고, 노트북 화면 데모가 그 위에 놓인다.
- AC-2: 페이지를 열면 노치 확대, 토토 따라가기, 줌아웃 순서로 자동 재생된다.
- AC-3: 줌아웃 뒤 문구와 버튼이 읽히고, 데모는 계속 움직인다.
- AC-4: 토토 모양과 상태 표현, 물방울 전환이 #75의 앱과 같다.
- AC-5: 움직임 줄이기 설정에서는 연출 없이 최종 화면이 바로 보인다.
- AC-6: 데스크톱과 모바일 너비, 라이트와 다크 모드에서 가로 스크롤 없이 텍스트가 읽힌다.
- AC-7: 상태 갤러리와 기능 벤토 그리드가 데스크톱과 모바일에서 넘치지 않는다.

미리보기 창이 백그라운드로 돌 때 브라우저가 화면 갱신을 늦춰서, 일부 항목은 캡처 대신 위치와 스타일 측정으로 확인했다.
노치 곡선 수정 뒤의 확대 모습, 영어 문구, 실제 폰 화면은 직접 확인하지 못했다.
