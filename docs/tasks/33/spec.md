## 목적

저장소를 처음 여는 사람이 앱이 무엇인지 알고 바로 설치할 수 있게 README를 사용자 중심으로 다시 쓴다.
랜딩 페이지(https://desktoto.pages.dev)와 같은 흐름과 톤을 쓴다.

## 작업 범위

### 포함

- 상단: 앱 이름, 한 줄 소개, 대표 이미지(랜딩 페이지 히어로 캡처), 배지(총 다운로드 수, 최신 버전, 요구 사항), 랜딩 페이지와 다운로드 링크
- 랜딩 페이지 섹션(히어로, 문제, 상태, 기능, 개인정보)을 `docs/images/readme/`에 PNG로 캡처해 README에 넣고, 설치는 복사할 수 있게 텍스트로 둔다
- 이미지는 라이트 모드 한 벌, 폭 1100px, 전체 약 400KB
- 설치 안내를 위쪽에 배치: Homebrew, dmg, `그래도 열기`, `xattr` 명령
- 개발자용 내용(빌드와 실행, 구조, 문서 링크)은 아래 별도 섹션으로 분리
- 문구, 링크, 명령 점검

### 제외

- 실제 앱 스크린샷과 GIF 추가(후속)
- 랜딩 페이지 디자인 변경, 라이선스 결정

## 설계 결정

- 파일 구조와 로직의 책임: `README.md` 한 파일만 고친다.
- 상태와 데이터 흐름: N/A (문서 전용)
- 선택한 방식과 이유: GitHub README는 CSS와 JS가 동작하지 않으므로 랜딩 페이지를 헤드리스 Chrome으로 섹션별 캡처해 이미지로 쓴다.
- 예외 처리: 다운로드 배지는 dmg와 zip 내려받은 횟수의 합이며 사람 수가 아니다.
