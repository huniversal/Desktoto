## 감시 틱의 판정

1. 세션 상태와 대기 종류를 읽는다.
2. 완료: 이전 틱에 `running`이었고 이번에 `completed`이며 대기 중이 아닌 세션. 시간이 지나 만료(`idle`)된 세션은 알리지 않는다. 질문을 남기고 끝난 세션은 완료가 아니라 대기로만 다룬다.
3. 새 대기: 이번 틱에 대기이고 이전 틱에는 대기가 아니던 세션. 계속 대기 중인 세션은 반복해서 알리지 않는다.
4. 달리는 개수: `running`이면서 대기가 아닌 세션 수.
5. 활동 시각 갱신: 달리는 세션이 있거나 대기 중이거나 방금 끝난 세션이 있으면 갱신한다.
6. 잠듦: 달리는 세션이 없고, 대기 중이 아니고, 폭죽이 재생 중이 아니며, 마지막 활동 후 600초가 지났을 때. 방금 끝남은 활동 시각만 갱신하고 잠듦 조건에는 들어가지 않는다.

## 알림과 소리

- 완료: Glass 소리를 한 번 내고 폭죽을 시작한다. 세션마다 "작업이 끝났어요" 알림을 보낸다. 패널이 열려 있으면 그 세션을 "방금 끝남" 줄로 강조하고, 닫혀 있으면 확인하지 않은 완료 점으로 쌓는다. 패널을 여는 순간 쌓인 점이 줄 강조로 넘어가고 아이콘의 점은 지워진다.
- 대기: Ping 소리를 한 번 내고 세션마다 알림을 보낸다. 질문이면 "답변이 필요해요", 아니면 "승인이 필요해요".
- 알림 제목: 세션 제목, 없으면 프로젝트 이름, 둘 다 없으면 "AI". 40자를 넘으면 자르고 말줄임표를 붙인다.
- 알림 설정이 꺼져 있으면 배너만 생략한다. 소리와 아이콘 표시는 설정과 무관하다.
- 알림을 누르면 그 세션을 연다.

## 패널

- 아이콘 좌클릭은 열고 닫는다. 우클릭은 먼저 패널을 닫고 설정 메뉴를 연다. 두 패널(사용량, 컨텍스트)을 모두 끈 경우에는 열지 않는다.
- 열 때: 확인하지 않은 완료를 줄 강조로 넘기고, 값을 채우고, 상태바 아이콘 아래에 배치한 뒤 0.15초 페이드로 보인다. Codex 실시간 조회를 즉시 요청한다.
- 닫을 때: 0.15초 페이드. 사라지는 도중 다시 열렸다면 숨기지 않는다. 숨겨질 때 강조 목록과 hover를 비운다.
- 바깥 클릭(전역 마우스 이벤트)과 Esc로 닫는다.
- 정렬: 승인 대기, 진행 중, 방금 끝남, 나머지 순서이고 같은 순위는 감시기가 준 순서를 유지한다.
- 테마는 패널 창의 외관에 적용한다(라이트, 다크, 시스템).
- 줄을 누르면 패널을 닫고 세션을 연다. 데스크탑 앱 대화는 링크로, 터미널 세션은 해당 탭으로 이동한다.

## 시작과 종료

시작 순서: 아이콘 이미지 만들기, 상태바 항목 연결, 패널 만들기, 테마 적용, Claude Code 연동 시도, Codex 실시간 조회 켜기, 알림 설정, 1초 타이머 시작과 즉시 한 번 실행.
종료할 때는 Codex 실시간 조회 프로세스를 정리한다. 원본은 시작할 때 `connectsClaudeCode`가 켜져 있고 Claude Code가 설치되어 있으면 연동을 시도했다(기본값 켬).
