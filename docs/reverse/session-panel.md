# 세션 패널 화면 동작

이슈 #10에서 원본 `~/Desktop/ai-run/Sources/AiRun/`의 `SessionPanelView.swift`와 `AppDelegate.swift`(`GlassPanel`, `updatePanelFrame`)를 읽고 정리한 동작이다.
구현은 `apps/macos/Sources/SessionPanel/`에 있다. 색, 간격, 반경, 그림자, 글자 크기, 모션 값은 [디자인 시스템](../design-system.md)을 따른다.

## 1. 구성

패널은 유리 카드 둘로 이루어지고, 둘을 `GlassEffectContainer(spacing: 8)` 안의 `VStack(spacing: 8)`에 쌓는다.

1. 사용량 카드: 설정에서 사용량 표시가 켜져 있고 사용량 목록이 비어 있지 않을 때만 그린다. 항상 위에 고정된다.
2. 세션 카드: 설정에서 컨텍스트 표시가 켜져 있을 때 그린다.

막대 색 모드(`barColorMode`)와 유리 단계(`glassStyle`)를 맨 위에서 한 번 `Environment`로 넣는다.

창 안쪽 여백은 위와 좌우가 그림자 여백(36)이고, 아래는 그림자 여백에 상세 줄 예약 높이(26)를 더한 값이다.
내용은 위쪽에 고정(`alignment: .top`)해서 높이가 변해도 위쪽 가장자리가 흔들리지 않는다.
`hoveredID`가 바뀔 때 0.25초 easeInOut 애니메이션을 건다. 창 크기는 그대로이고 유리 모양만 늘었다 줄어든다.

## 2. 세션 카드

- 세션이 없으면 "세션 없음" 한 줄(글자 13, 보조 글자, 위아래 24)을 보여준다.
- 줄 사이에는 구분선을 둔다(첫 줄 앞에는 없다). 줄은 전달된 순서 그대로 보여준다. 정렬은 앱 조립 쪽 책임이다.
- 카드는 `glassCard()`다.

### 줄 하나

위에서 아래로 쌓이고(간격 9) 가로 15, 세로 12 여백을 둔다.

1. 첫 줄: 제목, 가변 간격, 오른쪽 글자
   - 제목은 `title ?? projectName`, 한 줄, 끝을 자른다.
   - 방금 끝난 줄(`!isRunning`이고 `finishedIDs`에 id가 있음)에는 제목 오른쪽 위에 완료 점이 붙는다. 점은 글자 간격 3, 위로 9 올리고 `offset`이라 줄 높이를 늘리지 않으며 접근성 문구는 "확인하지 않은 완료"다.
   - 사용자 응답 대기 중이면 오른쪽 글자 자리에 알약이 나온다. 대기 종류가 질문이면 "답변 필요", 아니면 "승인 필요".
   - 아니면 오른쪽 글자는 사용률이다. 비율이 없으면 "-", 있으면 추정 표시 뒤에 정수 퍼센트(반올림)를 붙인다(예: `~42%`). 글자 12, 고정 폭 숫자, 방금 끝난 줄은 기본 글자색, 아니면 보조 글자색이다.
2. 막대: 사용률 비율을 컨텍스트 임계값(경고 0.6, 위험 0.85)으로 그린다.
3. 상세 줄: 이 줄에 마우스가 올라와 있을 때만 나타난다(페이드). 왼쪽에 모델 이름(없으면 "모델 알 수 없음", 한 줄), 오른쪽에 `사용 토큰 / 창 토큰`이다. 글자 11, 보조 글자색, 값이 하나라도 없으면 "-"다.

### 사용률 비율

`usedTokens`와 `windowTokens`가 모두 있고 `windowTokens > 0`일 때만 `min(usedTokens / windowTokens, 1)`이다. 아니면 없음이다.
창 크기를 추정한 값(`isWindowEstimated`)에는 "~"를 붙인다. 퍼센트와 상세 줄의 창 토큰 앞에 붙는다.

### 토큰 수 문구

- 1,000,000 이상: 소수 없이 떨어지면 `2M`, 아니면 소수 첫째 자리 `1.5M`
- 1,000 이상: `count / 1000` 정수 나눗셈 뒤 `K` (예: 1999는 `1K`)
- 그 미만: 숫자 그대로

### 클릭과 hover

- 줄 전체가 눌리는 영역이다. `canOpen`(열 링크가 있거나 터미널 세션)일 때만 클릭이 모델의 열기 콜백을 호출하고 포인터가 손가락 모양이 된다.
- hover가 들어오면 `hoveredID`를 그 id로 두고, 나가면서 값이 아직 그 id일 때만 비운다.

### 흐르는 배경

진행 중(`isRunning`) 줄만 뒤에 `FlowingGradientBackground`를 깐다. 줄 모양(반경 12)으로 잘리고 터치를 받지 않으며 위아래로 3씩 안쪽에 둔다.
시작과 끝에서 1.5초 easeInOut으로 서서히 나타나고 사라진다.

## 3. 사용량 카드

AI(`ToolUsage`)마다 블록 하나이고 블록 사이에 구분선을 둔다. 카드는 `glassCard()`다.

블록은 가로 15, 세로 10 여백, 간격 8이다.

1. 위 줄: AI 이름(글자 13, 굵게), 가변 간격, 낡은 값 문구. 문구는 마지막 갱신 후 600초 이상일 때만 `N분 전 기준`, `N시간 전 기준`, `N일 전 기준`이다(`ToolUsage.createStaleText`, #6).
2. 5시간 창이 있으면 "5시간" 줄, 주간 창이 있으면 "주간" 줄.

창 줄은 왼쪽부터 라벨(폭 32), 막대(사용량 임계값 경고 0.8, 위험 0.95), 퍼센트(폭 34, 오른쪽 정렬, 반올림 정수와 `%`, 글자 11 중간 굵기), 초기화까지 남은 시간(폭 70, 오른쪽 정렬, 한 줄)이다. 간격은 8이다.

### 초기화까지 남은 시간

`resetsAt`이 없으면 빈 문자열이다. 있으면 `(resetsAt - 현재)`를 분으로 내림하고 0 미만은 0으로 한다.

| 조건 | 문구 |
| --- | --- |
| 1일(1440분) 이상 | `N일 M시간` |
| 1시간 이상 | `N시간 M분` |
| 그 미만 | `N분` |

## 4. 투명 패널 창 (`GlassPanel`)

테두리 없음, 활성화하지 않는 패널(`.borderless`, `.nonactivatingPanel`)이다.
불투명하지 않고 배경은 투명이며, 시스템 그림자는 끈다(둥근 유리가 아니라 네모난 창 경계로 그려지기 때문이다. 그림자는 SwiftUI가 그린다).
창 수준은 팝업 메뉴, 모든 스페이스와 전체 화면 보조 창에 나타나고(`transient`), 닫을 때 해제되지 않는다.
키 창이 될 수 있어서 Esc(`cancelOperation`)를 받으면 `onCancel`을 호출한다.

## 5. 창 위치

내용 크기(그림자 여백 포함)를 `size`, 상태바 아이콘 창의 프레임을 `buttonFrame`, 아이콘이 있는 화면의 보이는 영역을 `visibleFrame`, 그림자 여백을 `margin`(36)이라 하면:

- `alignedX = buttonFrame.minX - margin`
- `minX = visibleFrame.minX + 8 - margin`
- `maxX = visibleFrame.maxX - size.width - 8 + margin`
- `originX = min(max(alignedX, minX), max(minX, maxX))`
- `originY = buttonFrame.minY - 6 - size.height + margin`

유리 모양이 아이콘 왼쪽 끝에 맞고, 아이콘 아래 6만큼 떨어지며, 화면 좌우 8 안쪽을 넘지 않는다.
화면 영역이 창보다 좁아 `maxX < minX`이면 `minX`가 이긴다.

## 6. 원본에서 앱 쪽이 맡는 것 (이 이슈 범위 밖)

세션 정렬, 패널 열기와 닫기(페이드 0.15초), 열려 있는 동안 2초 갱신, 바깥 클릭 감지, 테마를 창 외관에 적용하는 일, 완료와 대기 알림, 줄 클릭 시 세션 열기는 #11에서 조립한다.
